# SVM Equity Signal Classification — Interview Revision

## Project Objective

Predict whether the next-day stock price will break above the current Bollinger upper band.

---

## Final Features

The final model uses three features:

* `PCHG28` — 28-day price change
* `VCHG14` — 14-day volume change
* `VCHG7` — 7-day volume change

The original project engineered **44 features** and reduced them to **3 final features** through multiple feature-selection stages.

---

## Why TimeSeriesSplit?

`TimeSeriesSplit` preserves chronological order when training and validating the model.

The logic is:

**Past → Future**

This is important because random splitting could allow future information to enter the training process.

Main purpose:

> Avoid data leakage.

---

## Why StandardScaler?

SVM is sensitive to differences in feature scale.

`StandardScaler` transforms the features onto comparable scales before model training.

Important rule:

* Training data: `fit_transform()`
* Testing data: `transform()`

The scaler must only be fitted on the training data to avoid data leakage.

## Model Evaluation

### ROC AUC

ROC AUC measures how well the model separates positive and negative cases across different classification thresholds.

It is particularly useful when the classes are imbalanced.

---

### Precision

Precision answers:

> Of all alerts generated by the model, how many are actually positive?

Higher precision means fewer false alerts.

---

### Recall

Recall answers:

> Of all actual positive cases, how many did the model successfully identify?

Higher recall means fewer positive cases are missed.

---

### False Positive

A False Positive occurs when:

> The model generates an alert, but the case is actually negative.

**Financial Crime Example:**

A normal transaction is incorrectly flagged as suspicious.

---

### False Negative

A False Negative occurs when:

> The model does not generate an alert, but the case is actually positive.

**Financial Crime Example:**

A genuinely suspicious transaction is missed.
